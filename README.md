# Amazon ML Challenge - Business Entity Resolution

This repository contains the complete solution for the Amazon ML Challenge on Business Entity Resolution.

## Project Overview
- Entity Resolution across multi-source product datasets
- Candidate Generation & Blocking
- Feature Engineering (string similarity, embeddings, token overlaps)
- Machine Learning Models & Ensemble (LightGBM, XGBoost, CatBoost)
- Inference pipeline for generating candidate pairs and match predictions

## Project Structure
- `TEAM_submission/code/business_entity_resolution/`: Main code directory
  - `src/`: Core source modules (`blocking.py`, `candidate_generation.py`, `models.py`, `feature_engineering.py`, `inference.py`, `main.py`, etc.)
  - `requirements.txt`: Python dependencies
- `TEAM_submission/Documentation_template.md`: Methodology and architectural documentation
